# Security Policy

## Reporting a concern

Please do not open a public issue containing sensitive technical details, credentials, private data, or information about a real organisation or system.

Use a private contact route through the repository owner to report a security concern. Include only the minimum information needed to reproduce and understand the issue.

## Scope

This repository contains educational utilities, synthetic examples, and templates. Security reports are most useful when they concern:

- unsafe handling of untrusted input;
- accidental exposure of sensitive information;
- dependency or packaging issues;
- misleading validation behaviour that could create a false sense of assurance.

## Disclosure

Please allow reasonable time for review and remediation before publishing technical details.
